# 資料匯入與處理系統

本系統的調酒資料來自 Difford's Guide 和 IBA（國際調酒師協會），透過自動化腳本進行資料爬取、翻譯、標籤生成和匯入。

## 資料來源

### 1. Difford's Guide
- **數量**：約 8,000+ 款調酒
- **內容**：完整配方、製作步驟、歷史故事、專業評分、營養資訊
- **語言**：英文（已翻譯為中文）
- **位置**：`data/diffordsguide/` 和 `data/diffordsguide_trans/`

### 2. IBA（International Bartenders Association）
- **數量**：約 80+ 款官方認證調酒
- **內容**：標準配方、分類
- **語言**：英文
- **位置**：`data/IBA_csv/` 和 `data/IBA_xlsx/`

## 資料處理流程

### 階段 1：資料爬取

使用網路爬蟲從 Difford's Guide 網站取得調酒資料。

**相關腳本**：
- 位置：專案外部（爬蟲腳本）
- 輸出：`data/diffordsguide/*.json`（每個調酒一個 JSON 檔案）

### 階段 2：資料翻譯

將英文調酒資料翻譯為中文，包括名稱、材料、步驟、描述等。

**相關腳本**：
- `scripts/translate_diffordsguide.py`

**翻譯內容**：
- 調酒名稱
- 分類
- 材料名稱和描述
- 製作步驟
- 歷史故事
- 評論

**輸出**：
- `data/diffordsguide_trans/*.json`

### 階段 3：標籤生成

這是最關鍵的步驟，為每個調酒自動生成結構化的標籤，用於後續的搜尋、篩選和推薦。

**相關腳本**：
- `scripts/generate_tags.py`

#### 標籤分類系統

標籤被組織成四個主要類別，儲存在 `tags_categorized` 欄位：

##### 1. Base Spirits（基酒）
調酒的主要酒精基底，通常是用量最多的烈酒。

**標籤範例**：
- Vodka（伏特加）
- Gin（琴酒）
- Rum（蘭姆酒）
- Whiskey（威士忌）
- Tequila（龍舌蘭）
- Brandy（白蘭地）
- Liqueurs（香甜酒）
- Wine-based（葡萄酒基底）
- Beer-based（啤酒基底）
- Non-alcoholic（無酒精）

**生成邏輯**：
1. 分析材料清單（`ingredients` 欄位）
2. 識別烈酒類材料
3. 根據用量或順序判斷主要基酒
4. 可能包含 1-2 種基酒（如混合基底調酒）

##### 2. Flavors（風味）
調酒的主要風味特徵，從材料、描述、評論中提取。

**標籤範例**：
- Citrus（柑橘）
- Berry（莓果）
- Tropical（熱帶水果）
- Herbal（草本）
- Floral（花香）
- Spicy（辛香料）
- Sweet（甜味）
- Sour（酸味）
- Bitter（苦味）
- Nutty（堅果）
- Coffee（咖啡）
- Chocolate（巧克力）
- Mint（薄荷）
- Smoky（煙燻）

**生成邏輯**：
1. 分析材料中的水果、香料、香草等
2. 從歷史描述和評論中提取風味詞彙
3. 使用 NLP 技術識別風味關鍵字
4. 每個調酒可能有 2-5 個風味標籤

##### 3. Ingredients（特殊材料）
特別值得標註的材料，通常是特色或獨特成分。

**標籤範例**：
- Egg（蛋）
- Cream（奶油）
- Coconut（椰子）
- Ginger（薑）
- Honey（蜂蜜）
- Champagne（香檳）
- Absinthe（苦艾酒）
- Bitters（苦精）
- Soda（汽水）
- Juice（果汁）

**生成邏輯**：
1. 從材料清單中識別特殊成分
2. 標記過敏原（如蛋、乳製品）
3. 標記素食/非素食材料
4. 標記稀有或高級材料

##### 4. Styles（風格）
調酒的整體風格、特性、適用場合。

**標籤範例**：
- Classic（經典）
- Modern（現代）
- Tiki（提基）
- Sour（酸酒）
- Fizz（氣泡）
- Martini-style（馬丁尼風格）
- Shot（烈酒）
- Long drink（長飲）
- Digestif（餐後酒）
- Aperitif（餐前酒）
- Frozen（冰沙）
- Hot（熱飲）
- Refreshing（清爽）
- Strong（濃烈）
- Elegant（優雅）
- Party（派對）

**生成邏輯**：
1. 從分類（category）推斷
2. 從名稱中識別風格關鍵字（如 "Martini", "Sour"）
3. 從製作方法判斷（如 shake → refreshing）
4. 從 More Categories 中提取

#### 標籤生成流程

```
調酒 JSON → 提取材料 → 識別基酒 → 分析風味 → 標記材料 → 判斷風格 → 生成 tags_categorized
```

**具體步驟**：

1. **載入調酒資料**：讀取 JSON 檔案
2. **材料分析**：
   - 解析 `ingredients` 和 `ingredients_detail`
   - 識別每種材料的類型和用量
3. **基酒識別**：
   - 匹配烈酒關鍵字（vodka, gin, rum...）
   - 根據用量排序確定主要基酒
4. **風味提取**：
   - 掃描材料名稱中的風味詞
   - 分析 `history` 和 `review` 中的描述
   - 使用預定義的風味詞典匹配
5. **材料標記**：
   - 識別特殊成分（蛋、奶油等）
   - 標記過敏原
6. **風格判斷**：
   - 從 `category` 和 `more_categories` 提取
   - 從名稱中識別風格關鍵字
   - 根據製作方法推斷
7. **儲存標籤**：
   - 將四類標籤整合到 `tags_categorized` 欄位
   - 更新 JSON 檔案

#### 標籤品質保證

**驗證腳本**：
- `scripts/validate_tags.py`

**驗證項目**：
- 每個調酒至少有 1 個基酒標籤
- 風味標籤數量合理（2-5 個）
- 標籤拼寫正確
- 標籤與材料一致

### 階段 4：翻譯表匯入

建立中英文對照表，用於前端顯示和搜尋。

**相關腳本**：
- `scripts/import_trans_table.py`
- `scripts/import_tags_trans.py`

**翻譯表內容**：
- 材料名稱（英→中）
- 調酒分類（英→中）
- 標籤名稱（英→中）

**資料位置**：
- `data/trans_tables/*.json`
- `data/tag_translations.json`

**MongoDB 集合**：
- `translations`
- `tag_translations`

### 階段 5：資料匯入 MongoDB

將處理好的調酒資料匯入 MongoDB 資料庫。

#### Difford's Guide 匯入

**相關腳本**：
- `scripts/import_diffordsguide.py`（英文）
- `scripts/import_diffordsguide_zh.py`（中文）

**匯入流程**：
1. 讀取所有 JSON 檔案
2. 清理和驗證資料
3. 匯入到 `cocktails` 集合（英文）
4. 匯入到 `cocktails_zh` 集合（中文）

**資料欄位對應**：
參考 `backend_flask/app/models.py` 中的 `Cocktail.create()` 方法。

**匯入指令**：
```bash
cd scripts
python import_diffordsguide.py
python import_diffordsguide_zh.py
```

#### IBA 調酒匯入

**相關腳本**：
- `scripts/import_IBA.py`

**匯入流程**：
1. 讀取 CSV/XLSX 檔案
2. 轉換為標準格式
3. 匯入到 `cocktails` 集合
4. 標記為 IBA 官方認證

**匯入指令**：
```bash
cd scripts
python import_IBA.py
```

## 標籤應用場景

### 1. 屬性篩選

使用者可以根據標籤精確篩選調酒：

**前端篩選器**：
- 基酒選擇器：多選基酒類型
- 風味選擇器：多選風味標籤
- 風格選擇器：多選風格標籤

**後端實現**：
`Cocktail.filter_cocktails()` 方法支援標籤篩選。

### 2. 推薦系統

標籤是推薦系統的核心特徵：

**用戶偏好分析**：
- 統計用戶喜歡的調酒中最常出現的基酒
- 統計用戶喜歡的調酒中最常出現的風味
- 統計用戶喜歡的調酒中最常出現的風格

**相似度計算**：
- 基酒匹配：每個匹配的基酒 +4 分
- 風味匹配：每個匹配的風味 +2 分
- 風格匹配：每個匹配的風格 +1 分

參考：`DrinkingRecord.calculate_similarity_score()` 方法

### 3. 語義搜尋

標籤用於增強 RAG 系統的搜尋能力：

**向量化內容**：
- 將標籤與描述文字一起嵌入
- 提高語義搜尋的準確度
- 支援模糊的口味描述匹配

### 4. AI 工具

AI 酒保的工具函數使用標籤進行篩選：

**filter_by_attributes 工具**：
- 支援根據 `base_spirit` 篩選
- 支援根據 `flavor` 篩選
- 支援根據 `style` 篩選

## MongoDB 資料庫結構

### 集合（Collections）

#### cocktails（英文調酒資料）
- **文檔數量**：約 8,000+
- **主要欄位**：
  - `cocktail_id`：唯一識別碼
  - `name`：調酒名稱（英文）
  - `ingredients`：材料清單
  - `method_sections`：製作步驟
  - `ratings`：評分資訊
  - `taste_profile`：風味檔案（強度、甜度）
  - `tags_categorized`：結構化標籤
  - `history`：歷史故事

#### cocktails_zh（中文調酒資料）
- **文檔數量**：約 8,000+
- **主要欄位**：
  - `cocktail_id`：與英文版對應
  - `name_zh`：調酒名稱（中文）
  - `ingredients_zh`：材料清單（中文）
  - `method_sections_zh`：製作步驟（中文）
  - `category_zh`：分類（中文）

#### translations（翻譯表）
- **用途**：材料、分類的中英對照
- **結構**：`{ "en": "Vodka", "zh": "伏特加", "type": "ingredient" }`

#### tag_translations（標籤翻譯）
- **用途**：標籤的中英對照
- **結構**：`{ "en": "Citrus", "zh": "柑橘", "category": "flavors" }`

## 維護與更新

### 定期任務

1. **爬取新調酒**：每月更新 Difford's Guide 資料
2. **驗證標籤品質**：執行 `validate_tags.py`
3. **更新翻譯**：補充新材料和標籤的翻譯
4. **資料庫優化**：執行 `scripts/optimize_mongodb.py`

### 資料庫優化

**相關腳本**：
- `scripts/optimize_mongodb.py`

**優化項目**：
- 建立索引（name, category, tags）
- 清理重複資料
- 壓縮資料庫

### 問題排查

**常見問題**：

1. **標籤缺失**：執行 `generate_tags.py` 重新生成
2. **翻譯錯誤**：更新翻譯表後重新匯入
3. **資料不一致**：使用 `update_cocktails_data.py` 批次修正
