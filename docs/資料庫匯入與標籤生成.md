# 資料庫匯入與標籤生成系統

## 系統概述

本系統負責將調酒資料從外部來源批次匯入到 MongoDB 資料庫，並自動生成智能標籤系統，使調酒能夠被高效搜尋和分類。所有相關腳本位於 `scripts/` 目錄。

---

## 一、資料來源

### 支援的資料來源

| 資料來源 | 檔案位置 | 匯入腳本 | 調酒數量 |
|---------|---------|---------|---------|
| **Difford's Guide** | `data/diffordsguide/` | `import_diffordsguide.py` | ~3000+ |
| **Difford's Guide (中文)** | `data/diffordsguide_trans/` | `import_diffordsguide_zh.py` | ~3000+ |
| **IBA 官方調酒** | `data/IBA_csv/` 或 `IBA_xlsx/` | `import_IBA.py` | ~90 |
| **標籤翻譯表** | `data/tag_translations.json` | `import_tags_trans.py` | - |
| **翻譯對照表** | `data/trans_tables/` | `import_trans_table.py` | - |

### 資料格式

原始資料為 JSON 格式，每個調酒一個檔案。資料包含調酒名稱、材料清單、製作步驟、分類等資訊。

## 二、Difford's Guide 匯入

### 腳本位置

`scripts/import_diffordsguide.py`

### 功能說明

此腳本負責將 Difford's Guide 的調酒資料批次匯入資料庫，並進行資料清理、格式轉換和欄位推斷。

### 執行步驟

1. **讀取 JSON 檔案**
   - 掃描 `data/diffordsguide/` 目錄
   - 載入所有 `.json` 檔案
   - 驗證檔案格式

2. **資料格式轉換**
   - 轉換為符合 MongoDB Schema 的格式
   - 處理材料清單（分離名稱和用量）
   - 轉換製作步驟為陣列格式
   - 清理異常字元和格式

3. **欄位推斷**
   - 自動推斷調酒分類
   - 計算製作難度
   - 生成初步標籤

4. **批次匯入**
   - 使用 `bulk_write` 批次操作提升效率
   - 重複資料使用 `update` 更新
   - 新資料使用 `insert` 插入
   - 錯誤處理與日誌記錄

5. **產生報告**
   - 成功匯入數量
   - 失敗數量與原因
   - 錯誤詳情列表

### 使用方式

```bash
cd scripts
python import_diffordsguide.py
```

### 自動推斷邏輯

#### 分類推斷 (Category Inference)

**基於名稱關鍵字**：
- 名稱包含 "Martini" → 歸類為 Martini 類
- 名稱包含 "Margarita" → 歸類為 Margarita 類
- 名稱包含 "Sour/Fizz/Collins" → 歸類為 Sour 類
- 名稱包含 "Tiki/Mai Tai/Zombie" → 歸類為 Tiki 類

**基於主要基酒**：
- 含 Vodka → Vodka-based
- 含 Gin → Gin-based
- 含 Rum → Rum-based
- 含 Tequila → Tequila-based

#### 難度推斷 (Difficulty Inference)

**計算公式**：

- **簡單 (easy)**：
  - 材料 ≤ 3 種
  - 步驟 ≤ 3 步
  - 無需特殊技巧

- **中等 (medium)**：
  - 材料 ≤ 5 種
  - 步驟 ≤ 6 步
  - 基本調酒技巧

- **困難 (hard)**：
  - 材料 > 5 種
  - 步驟 > 6 步
  - 需要進階技巧（如分層、火焰等）

## 三、標籤生成系統

### 核心腳本

`scripts/generate_tags.py`

### 設計理念

標籤系統採用**四個維度**的分類方式，讓用戶能從不同角度搜尋和篩選調酒：
1. 基酒類型
2. 風味特徵
3. 主要材料
4. 風格/類型

所有標籤使用**簡單易懂的詞彙**，面向調酒初學者和一般用戶設計。

---

### 維度一：基酒類型 (12 種)

#### 目的
快速識別調酒的主要基酒，幫助用戶根據偏好的酒類篩選。

#### 標籤清單

- **Gin**（琴酒）
- **Vodka**（伏特加）
- **Rum**（蘭姆酒）
- **Tequila**（龍舌蘭）
- **Whiskey**（威士忌）
- **Brandy**（白蘭地）
- **Mezcal**（梅斯卡爾）
- **Cachaça**（卡夏莎）
- **Pisco**（皮斯可）
- **Genever**（荷蘭琴酒）
- **Non-alcoholic**（無酒精）
- **Mixed Base**（混合基酒）

#### 識別方法

- 分析 `ingredients` 欄位中的材料清單
- 使用關鍵字匹配（如 "gin", "vodka"）
- 排除干擾詞（如 "ginger" 不算 "gin"）
- 識別多基酒情況（兩種以上基酒標記為 Mixed Base）

---

### 維度二：風味特徵 (20 種)

#### 目的
描述調酒的主要口味和風味特徵，幫助用戶找到符合口味偏好的調酒。

#### 標籤分類

**果香系**：
- citrusy（柑橘）
- fruity（果香）
- tropical（熱帶）

**苦甜系**：
- bittersweet（苦甜）
- sweet（甜味）
- sour（酸味）

**奶香系**：
- creamy（奶香）

**草本系**：
- herbal（草本）
- minty（薄荷）

**花香系**：
- floral（花香）

**辛香系**：
- spicy（辛辣）

**風味系**：
- coffee（咖啡）
- chocolate（巧克力）
- nutty（堅果）
- vanilla（香草）
- caramel（焦糖）

**特殊系**：
- smoky（煙燻）
- salty（鹹味）

**氣泡系**：
- bubbly（氣泡）
- effervescent（起泡）

#### 識別方法

- 分析材料關鍵字
- 分析調酒名稱
- 參考 `more_categories` 欄位

**範例**：
- 含 "lime juice" → citrusy
- 含 "mint" → minty
- 含 "campari" → bittersweet
- 含 "cream" → creamy

---

### 維度三：主要材料 (32 種)

#### 目的
標記調酒中的特色材料，方便用戶搜尋含有特定材料的調酒。

#### 標籤分類

**果汁類**：
- citrus（柑橘汁）
- pineapple（鳳梨）
- cranberry（蔓越莓）
- tomato（番茄）

**酒類**：
- vermouth（苦艾酒）
- champagne（香檳）
- prosecco（普羅賽克）
- wine（葡萄酒）

**利口酒類**：
- liqueur（利口酒）
- triple sec（橙酒）
- amaretto（杏仁酒）

**香料與食材**：
- mint（薄荷）
- ginger（薑）
- cucumber（小黃瓜）
- jalapeño（墨西哥辣椒）

**其他**：
- egg（蛋）
- bitters（苦精）
- soda（蘇打水）
- tonic（通寧水）

#### 識別方法

- 精確材料名稱匹配
- 支援複數形式和變體（如 "eggs" 匹配 "egg"）
- 區分相似名稱（如 "ginger" 和 "gin"）

---

### 維度四：風格/類型 (30 種)

#### 目的
描述調酒的整體風格、適用場景、製作方式等。

#### 標籤分類

**經典風格**：
- classic（經典）
- modern（現代）
- tiki（提基）

**口感風格**：
- refreshing（清爽）
- strong（烈酒）
- light（輕盈）
- rich（濃郁）

**製作方式**：
- shaken（搖盪）
- stirred（攪拌）
- built（直調）
- blended（攪拌機）
- layered（分層）

**適用場景**：
- party（派對）
- summer（夏日）
- brunch（早午餐）
- aperitif（餐前酒）
- digestif（餐後酒）

**特殊類型**：
- frozen（冰沙）
- hot（熱飲）
- shot（烈酒短飲）
- punch（潘趣酒）
- flip（翻轉）

#### 識別方法

- 主要來自 `more_categories` 欄位映射
- 名稱關鍵字輔助判斷
- 製作方法關鍵字識別

---

### 標籤生成流程

```
調酒原始資料
    ↓
分析材料清單 (ingredients)
    ↓
分析名稱 (name)
    ↓
分析分類 (more_categories)
    ↓
應用四維度規則映射
    ↓
生成標籤字典
    ├── base_spirits: []
    ├── flavors: []
    ├── ingredients: []
    └── styles: []
    ↓
扁平化為 tags 陣列
    ↓
儲存到 MongoDB
```

### 標籤儲存結構

```javascript
{
  "_id": ObjectId("..."),
  "name": "Mojito",
  // 扁平化標籤陣列，用於全文搜尋
  "tags": [
    "rum", "citrusy", "minty", "mint", 
    "refreshing", "classic", "summer"
  ],
  // 分類標籤，用於精確篩選
  "tags_categorized": {
    "base_spirits": ["rum"],
    "flavors": ["citrusy", "minty"],
    "ingredients": ["mint"],
    "styles": ["refreshing", "classic", "summer"]
  }
}
```

**用途區分**：
- `tags`：用於全文搜尋、模糊匹配、語義搜尋
- `tags_categorized`：用於分類篩選、精確查詢、維度分析

## 四、其他匯入腳本

### IBA 官方調酒匯入

**腳本**：`scripts/import_IBA.py`

**功能**：匯入國際調酒師協會（IBA）官方認證的調酒配方。

**資料來源**：
- `data/IBA_csv/` - CSV 格式
- `data/IBA_xlsx/` - Excel 格式

**特色**：
- 包含 IBA 官方分類（如 Unforgettables、Contemporary Classics）
- 標準化配方和用量
- 權威性高，適合初學者參考

### 標籤翻譯表匯入

**腳本**：`scripts/import_tags_trans.py`

**功能**：匯入標籤的多語言翻譯對照表。

**用途**：
- 支援中英文標籤切換
- 前端顯示本地化標籤
- 搜尋時支援多語言

### 翻譯對照表匯入

**腳本**：`scripts/import_trans_table.py`

**功能**：匯入調酒名稱、材料名稱的翻譯對照表。

**用途**：
- 統一翻譯標準
- 避免重複翻譯
- 人工校正結果

## 五、資料維護腳本

### 更新調酒資料

**腳本**：`scripts/update_cocktails_data.py`

**功能**：
- 批次更新特定欄位
- 重新生成標籤
- 修正資料錯誤
- 標準化欄位格式

**使用情境**：
- 標籤系統升級後重新生成所有標籤
- 修正批次資料錯誤
- 新增欄位並填充預設值

### 驗證標籤完整性

**腳本**：`scripts/validate_tags.py`

**功能**：
- 檢查所有調酒是否有標籤
- 統計標籤分佈
- 識別標籤缺失或異常的調酒
- 產生驗證報告

**輸出範例**：
```
✓ 總共 3000 個調酒
✓ 2980 個有標籤
✗ 20 個缺少標籤
✓ 基酒標籤覆蓋率：98%
✓ 風味標籤覆蓋率：95%
```

### 合併分類

**腳本**：`scripts/merge_categories.py`

**功能**：
- 合併重複或相似的分類
- 標準化分類名稱
- 處理多語言分類映射

**範例**：
- 將 "Refreshing" 和 "Fresh" 合併為 "refreshing"
- 將 "Whisky" 和 "Whiskey" 統一為 "whiskey"

## 七、翻譯工具

### 調酒名稱翻譯

**腳本**：`scripts/translate_diffordsguide.py`

**功能**：
- 將英文調酒名稱翻譯成中文
- 使用翻譯 API 或本地字典
- 人工校正結果

**翻譯策略**：
1. 優先使用翻譯對照表（已知翻譯）
2. 經典調酒使用標準中文名稱
3. 特殊名稱保留原文並加註音譯
4. 人工審核確保準確性

### 標籤翻譯

**檔案**：`data/tag_translations.json`

**內容**：標籤的多語言對照表

**格式**：
```json
{
  "refreshing": {
    "zh": "清爽",
    "en": "Refreshing"
  },
  "citrusy": {
    "zh": "柑橘",
    "en": "Citrusy"
  }
}
```

## 八、使用指南

### 完整匯入流程

**首次匯入**：
```bash
# 1. 匯入 Difford's Guide 資料
python scripts/import_diffordsguide.py

# 2. 匯入 IBA 官方調酒
python scripts/import_IBA.py

# 3. 生成標籤
python scripts/generate_tags.py

# 4. 匯入翻譯表
python scripts/import_tags_trans.py
python scripts/import_trans_table.py

# 5. 驗證資料
python scripts/validate_tags.py
```

**資料更新**：
```bash
# 1. 更新調酒資料
python scripts/update_cocktails_data.py

# 2. 重新生成標籤
python scripts/generate_tags.py

# 3. 驗證完整性
python scripts/validate_tags.py
```

### 注意事項

1. **執行前備份**：所有批次操作前建議備份資料庫
2. **執行順序**：按照順序執行腳本，避免相依性問題
3. **錯誤處理**：注意查看錯誤日誌，及時修正問題
4. **資料驗證**：匯入後務必執行驗證腳本確認完整性
