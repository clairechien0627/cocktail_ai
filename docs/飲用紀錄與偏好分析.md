# 飲用紀錄與偏好分析系統

飲用紀錄是本系統的核心功能之一，用戶可以記錄每一次的調酒體驗，系統會自動分析這些記錄，建立個人化的口味偏好檔案，作為推薦系統的基礎。

## 功能概述

飲用紀錄系統就像是你的**私人調酒日記**，不僅記錄喝過什麼，更重要的是：
- 記錄你對每杯酒的感受和評價
- 記錄飲用的情境和心情
- 自動分析你的口味偏好
- 為推薦系統提供個人化數據

## 飲用紀錄功能

### 記錄內容

每筆飲用紀錄包含以下資訊：

#### 1. 基本資訊
- **調酒名稱**：記錄是哪一款調酒
- **飲用時間**：記錄品嚐的日期和時間
- **地點**（可選）：在哪裡喝的（家中、酒吧、餐廳等）

#### 2. 個人評價
- **喜好程度**：四個等級
  - ❤️ **Loved**（超愛）：非常喜歡，會想再喝
  - 👍 **Liked**（喜歡）：喜歡這個口味
  - 😐 **Neutral**（普通）：不討厭但也不特別喜歡
  - 👎 **Disliked**（不喜歡）：不符合口味

- **個人筆記**（可選）：自由撰寫的心得和評論
  - 口感描述
  - 特別印象深刻的地方
  - 建議的調整
  - 任何想記錄的想法

#### 3. 情境標籤
記錄飲用時的場合和心情，有助於了解在什麼情境下適合喝什麼酒：

**預設標籤選項**：
- 🎉 **慶祝**：生日、升遷、達成目標
- 😌 **放鬆**：下班後、週末休閒
- 💑 **約會**：浪漫晚餐、特別時刻
- 👥 **聚會**：朋友聚會、派對
- 🧘 **獨飲**：自己一個人享受
- 🆕 **嘗鮮**：第一次嘗試新口味
- 💼 **工作後**：忙碌一天後的放鬆
- 🎊 **週末**：週末時光
- 🎁 **特殊場合**：節日、紀念日
- ☕ **日常**：平常的日子
- 💭 **懷舊**：想起某段回憶
- 🚀 **冒險**：嘗試不熟悉的風格

可以選擇多個標籤來完整描述當下的情境。

#### 4. 調酒快照
系統會自動保存調酒的基本資訊：
- 調酒名稱和圖片
- 分類和風味檔案
- 標籤資訊

**為什麼需要快照？**
即使調酒資料庫中的資料被更新或刪除，你的記錄仍然保留當時的資訊，確保歷史記錄的完整性。

### 記錄管理

#### 新增記錄
**觸發時機**：
- 從推薦頁面點擊「記錄飲用」
- 從 AI 對話中的調酒卡片點擊記錄
- 從調酒詳情頁點擊記錄
- 從收藏清單中記錄

**操作流程**：
1. 選擇喜好程度（必填）
2. 填寫個人筆記（可選）
3. 選擇情境標籤（可選）
4. 確認飲用時間（預設為當下）
5. 填寫地點（可選）
6. 儲存記錄

#### 查看記錄
**查看方式**：
- **時間軸檢視**：按時間排序查看所有記錄
- **依喜好篩選**：只看喜歡的、不喜歡的等
- **依日期篩選**：查看特定時間段的記錄
- **依情境篩選**：查看特定場合的記錄

#### 編輯記錄
可以隨時修改：
- 喜好程度
- 個人筆記
- 情境標籤
- 飲用時間
- 地點

#### 刪除記錄
不想要的記錄可以永久刪除。

### 同一調酒的多次記錄

系統**允許多次記錄同一款調酒**，這很重要因為：
- 不同時間、地點、心情下的體驗可能不同
- 自己調製 vs. 酒吧調製的差異
- 技術進步後的重新品嚐
- 記錄每次的嘗試和改進

**範例場景**：
```
Mojito 記錄 1 (2024-12-01)：喜歡｜在酒吧喝的，薄荷味很足
Mojito 記錄 2 (2024-12-10)：普通｜自己做的，好像糖加太多了
Mojito 記錄 3 (2024-12-14)：超愛｜改良配方後完美！
```

## 偏好分析系統

系統會自動分析所有飲用記錄，建立你的**個人化口味檔案**。

### 分析維度

#### 1. 喜愛標籤分析

**分析對象**：只分析標記為「喜歡」或「超愛」的調酒

**分析內容**：
- **最愛的基酒**（Top 3）
  - 統計喜歡的調酒中最常出現的基酒
  - 範例：琴酒（10次）、蘭姆酒（7次）、伏特加（5次）

- **最愛的風味**（Top 5）
  - 統計喜歡的調酒中最常出現的風味標籤
  - 範例：柑橘（12次）、薄荷（8次）、草本（6次）

- **最愛的風格**（Top 5）
  - 統計喜歡的調酒中最常出現的風格標籤
  - 範例：清爽（15次）、經典（10次）、酸酒（8次）

**應用**：這些資訊會直接用於推薦系統的相似度計算。

#### 2. 口味範圍分析

**分析對象**：只分析標記為「喜歡」或「超愛」的調酒

**分析內容**：
- **酒精強度範圍**（0-10）
  - 最小值：你能接受的最低強度
  - 最大值：你能接受的最高強度
  - 平均值：你最常選擇的強度

- **甜度範圍**（0-10）
  - 最小值：你能接受的最低甜度
  - 最大值：你能接受的最高甜度
  - 平均值：你最常選擇的甜度

**範例**：
```json
{
  "strength": { "min": 5, "max": 9, "avg": 7 },
  "sweetness": { "min": 2, "max": 6, "avg": 4 }
}
```

**解讀**：這位用戶偏好中高酒精強度（7）、低中甜度（4）的調酒，但也能接受範圍內的變化。

**應用**：推薦系統會優先推薦落在這個範圍內的調酒。

#### 3. 飲用習慣分析

**分析對象**：所有飲用記錄（不限喜好程度）

**分析內容**：

##### 時段分佈
記錄你在什麼時間最常喝調酒：
- **深夜**（00:00-06:00）
- **早晨**（06:00-12:00）
- **下午**（12:00-18:00）
- **晚上**（18:00-24:00）

**應用**：未來可以根據當前時段推薦適合的調酒。

##### 情境分佈
統計你最常在什麼場合喝調酒：
- 慶祝（15次）
- 放鬆（20次）
- 聚會（10次）
- 獨飲（8次）
- ...

**應用**：了解你的飲用習慣，提供更貼心的建議。

##### 地點分佈
統計你最常在哪裡喝調酒：
- 家中（25次）
- 酒吧（15次）
- 餐廳（8次）
- 未填寫地點（12次）

**應用**：了解你的飲用環境偏好。

### 統計資訊

系統會自動計算並顯示：

#### 基本統計
- **總飲用杯數**：你總共記錄了多少杯
- **偏好分佈**：
  - 超愛的有幾杯
  - 喜歡的有幾杯
  - 普通的有幾杯
  - 不喜歡的有幾杯

#### 最常喝的調酒（Top 5）
- 統計記錄次數最多的調酒
- 顯示調酒名稱、圖片、記錄次數
- **不限喜好程度**，純粹看喝的次數

**範例**：
```
1. Mojito (5次)
2. Gin Tonic (4次)
3. Margarita (3次)
```

#### 最喜歡的調酒（Top 5）
- 統計標記為「喜歡」或「超愛」的調酒
- 按最後飲用時間排序
- 顯示調酒名稱、圖片、喜好程度

**範例**：
```
1. Old Fashioned (超愛) - 最後飲用：2024-12-14
2. Negroni (喜歡) - 最後飲用：2024-12-12
3. Whiskey Sour (超愛) - 最後飲用：2024-12-10
```

## 偏好檔案的應用

### 1. 推薦系統核心

偏好分析是推薦系統的基礎：

**相似度計算**：
- 基酒匹配：候選調酒的基酒在你的 Top 3 中 → +4分
- 風味匹配：候選調酒的風味在你的 Top 5 中 → +2分
- 風格匹配：候選調酒的風格在你的 Top 5 中 → +1分
- 口味接近度：候選調酒的強度和甜度在你的範圍內 → 最高+8分

詳見：[推薦系統.md](./推薦系統.md)

### 2. AI 酒保個人化

AI 酒保會使用你的偏好來：
- 理解你的口味傾向
- 推薦更符合你喜好的調酒
- 解釋為什麼推薦某款酒給你

**工具調用**：
`get_user_drinking_preferences` 工具會提取你的偏好資料，供 AI 參考。

### 3. 搜尋結果優化

當你搜尋或篩選調酒時，系統可以：
- 根據你的偏好排序結果
- 標記你可能會喜歡的調酒
- 過濾不符合口味的選項

### 4. 個人化儀表板

在個人頁面顯示：
- 你的口味雷達圖（強度、甜度、風味等）
- 最常喝的基酒分佈
- 飲用習慣時間線
- 探索進度（嘗試了多少不同的調酒）

## 冷啟動處理

**什麼是冷啟動？**
新用戶還沒有任何飲用記錄時，系統沒有數據可以分析。

**解決方案**：

### 階段 1：新手引導（0-5 筆記錄）
- 推薦**經典入門調酒**（高評分、簡單、廣受歡迎）
- 鼓勵用戶嘗試不同基酒和風格
- 快速建立基礎偏好數據

### 階段 2：探索期（6-20 筆記錄）
- 開始根據初步偏好推薦
- 仍然保持較高的多樣性
- 幫助用戶探索更多可能性

### 階段 3：穩定期（20+ 筆記錄）
- 偏好分析足夠準確
- 推薦系統達到最佳效果
- 持續優化和細化偏好

## 隱私與資料安全

### 私密性
- **飲用記錄完全私密**：只有你自己看得到
- 不會分享給其他用戶
- 不會公開顯示

### 資料擁有權
- 你完全擁有自己的記錄
- 可以隨時匯出所有資料
- 可以隨時刪除所有記錄

### 偏好分析
- 所有分析都在後端自動進行
- 只用於改善你的個人體驗
- 不會用於其他目的

## 使用建議

### 養成記錄習慣
- **即時記錄**：喝完馬上記錄，印象最深刻
- **詳細筆記**：寫下當下的感受，日後回顧很有趣
- **誠實評價**：真實記錄喜好，推薦才會準確

### 善用情境標籤
- 選擇 2-3 個標籤描述當下情境
- 有助於未來回憶這杯酒的場景
- 可以看出自己在不同場合的偏好差異

### 多次記錄同一調酒
- 記錄每次不同的體驗
- 追蹤自己調製技巧的進步
- 比較不同場所的差異

### 定期回顧
- 查看統計資訊，了解自己的變化
- 發現新的口味傾向
- 計劃下次要嘗試的方向
